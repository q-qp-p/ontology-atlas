## 2026-10-15 — "Concepts" on the map's surfaces counts the four kinds the map draws

**Why**: One vault of 99 nodes read as six numbers: INDEX 100 documents, a tree root of 92, the hub 97, the readout 97, the screen-reader census 98 and full detail 99. A person comparing the INDEX with full detail could not tell which was true.
**Prior**: The 2026-09-19 canonical census (`computeCanonicalCensus`, "counts project and document but excludes the reader sentinel", from #1704) is narrowed: it now counts project, domain, capability and element. `isCanonicalConcept` keeps its membership for Git's changed-concept list, so a document file still reads as a concept there.
**Decision**: `computeCanonicalCensus` counts what the map draws (97 for the dogfood vault). The INDEX census, the INDEX project row, the hub, the readout, full detail's census and its reach denominator use it; the folder's Markdown count stays labelled as documents. A selected concept's readout names it with its own count.
**Dissent**: The specification lists `document` as an authorable concept kind, so 98 is also defensible; answered by scope: these surfaces describe the map, and a document is reached as evidence of a drawn concept, not drawn itself.
**Falsifier**: Two surfaces on the map route state different concept counts for the same vault, or a person reads the insights headline (which still counts documents) against the map and reports the disagreement.
**Owner**: Project owner, via the M5 map-detail brief of 2026-10-15.
